# Returnista plugin

Ask about your returns in plain language: return reasons, sizing and fit, refunds, exchanges and store credit, per Store and period, using your Returnista account.

Install in Claude Code:

```
/plugin install returnista --marketplace returnista/ai-plugin
```

Then sign in to Returnista when asked (`/mcp`, choose returnista, Authenticate).
